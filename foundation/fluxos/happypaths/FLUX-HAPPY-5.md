# FLUX-HAPPY-5
### Cliente acompanha pedido em tempo real

**Perfis:** 👤

[← Índice happy path](README.md)

---

**Perfis:** 👤 Cliente

```
Após finalizar, o cliente abre a tela de acompanhamento e vê cada atualização
```

**Passo a passo:**

| # | Quem | O que acontece |
|---|------|----------------|
| 1 | 👤 Cliente | Após o pedido ser feito, toca em **"Acompanhar pedido"** |
| 2 | 👤 Cliente | Vê uma **linha do tempo** (timeline) com os estados do pedido |
| 3 | 👤 Cliente | Estado inicial: **Pedido recebido** ✅ |
| 4 | 👤 Cliente | Atualiza a tela ou aguarda — vê **Aceito pela loja** ✅ |
| 5 | 👤 Cliente | Em seguida: **Em preparo** 🍳 |
| 6 | 👤 Cliente | Depois: **Pronto para retirada** 📦 |
| 7 | 👤 Cliente | Depois: **Motoboy a caminho** 🛵 |
| 8 | 👤 Cliente | Depois: **Saiu para entrega** 🚀 |
| 9 | 👤 Cliente | Por fim: **Entregue** ✅ |
| 10 | 👤 Cliente | Pode acessar o histórico do pedido a qualquer momento depois |

> 💡 Sem rastreamento GPS no mapa — só a timeline de estados.
